## What I learned

- `datetime.today()` gives the current date **and** time, while `date.today()`
  gives just the date. They're different types (`datetime` vs `date`).
- A `date` has handy attributes like `.year`, `.month` and `.day`.
- Subtracting one date from another gives a `timedelta`, a gap in time.
  Internally it's stored as days, seconds and microseconds, and it can be
  negative.
- You can build a `timedelta` yourself, e.g. `timedelta(days=4, hours=10)`,
  and add it to a `datetime` to work out a time in the future.

## Code

Counting down to Christmas with date subtraction:

```python
from datetime import date

todaydate = date.today()
christmas = date(2026, 12, 25)
days_until_christmas = christmas - todaydate

if christmas != todaydate:
    print("sorry, there are still", days_until_christmas.days, "days until Christmas!")
else:
    print("Merry Christmas!")
```

And adding a `timedelta` to the current time to get an ETA six hours from now:

```python
from datetime import datetime, timedelta

eta = timedelta(hours=6)
print("today + eta:", datetime.today() + eta)
```
